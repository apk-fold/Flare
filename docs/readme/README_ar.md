# Flare

أتمتة لنظام **Android** على غرار تطبيق «الاختصارات» من Apple، لكنها أقوى من «الأوضاع والإجراءات الروتينية» في Samsung:
**مشغِّل** (اتصال جهاز بلوتوث، Wi-Fi، الشاحن، الوقت، فتح تطبيق، فتح الهاتف القابل للطي…)، و**شروط** اختيارية، ثم
**سلسلة من الإجراءات** (إعدادات، تطبيقات، موسيقى، أوامر…)، إضافةً إلى إجراءات «عند الانتهاء» تعيد كل شيء في الوقت المناسب.

مثال مرفق بالتطبيق: عند اتصال الهاتف بالسيارة عبر البلوتوث، يفعّل Flare وضع «عدم الإزعاج»، ويضبط مستوى الصوت، ويشغّل
الموسيقى في [Opus](https://github.com/apkangelo/opus) ويفتح الخرائط؛ وعند قطع الاتصال يوقف الموسيقى مؤقتًا ويطفئ «عدم
الإزعاج».

مصمَّم لهاتف Galaxy Z Fold بواجهة One UI: مشغِّلات «طي الهاتف / فتحه»، ومن دون روت (لم تعد Samsung تسمح بفتح قفل
محمِّل الإقلاع) بفضل Shizuku.

## التنزيل

**[Flare.apk](https://github.com/apkangelo/Flare/releases/latest/download/Flare.apk)** (‏Android 8 أو أحدث). افتح
الملف، واسمح بالتثبيت من هذا المصدر، ثم اضغط *تثبيت*. تُثبَّت التحديثات فوق الإصدار السابق دون فقدان الأتمتة لديك. كل
الإصدارات موجودة في تبويب [*Releases*](https://github.com/apkangelo/Flare/releases)، ويبنيها GitHub Actions مع كل تعديل.

## ما الذي يفعله Flare

**المشغِّلات (27)**: اتصال / فصل جهاز بلوتوث (يكفي جزء من الاسم: «Media Nav» يتعرّف على «MEDIA-NAV»)، الاتصال / قطع
الاتصال بشبكة Wi-Fi، وضع الطيران، توصيل / فصل الشاحن، مستوى البطارية، تشغيل الهاتف، تشغيل / إطفاء الشاشة، إلغاء القفل،
**طي الهاتف / فتحه**، توصيل / فصل السماعات، وقت وأيام محددة، كل X دقيقة، فتح / إغلاق تطبيق، وصول إشعار (التطبيق، النص)،
مكالمة واردة / بدء مكالمة / انتهاؤها، وصول رسالة نصية، الوصول إلى مكان / مغادرته.

**الشروط (11)**: فترة زمنية، أيام الأسبوع، البطارية، قيد الشحن، جهاز بلوتوث متصل، شبكة Wi-Fi، مطوي / مفتوح، السماعات،
الشاشة قيد التشغيل، وضع الرنين، التطبيق المعروض.

**الإجراءات (40)**
- *الاتصالات*: Wi-Fi، بيانات الجوّال، البلوتوث، وضع الطيران، NFC، الموقع (تشغيل، إيقاف، تبديل).
- *الشاشة*: السطوع، مهلة الشاشة، التدوير، الوضع الداكن، إبقاء الشاشة مضاءة أثناء الشحن، توفير الطاقة، المصباح، القفل،
  تشغيل الشاشة، لقطة شاشة.
- *الصوت والوسائط*: وضع الرنين، «عدم الإزعاج»، مستوى صوت كل نوع، تشغيل / إيقاف مؤقت / التالي، تشغيل الموسيقى في تطبيق
  محدد، قراءة نص بصوت عالٍ، الاهتزاز.
- *التطبيقات*: فتح تطبيق أو رابط أو رابط عميق (`opus://flow`، `tel:`، `geo:`…)، الملاحة في الخرائط، فرض الإيقاف، فتح
  صفحة إعدادات، إرسال intent.
- *التحكم في الشاشة*: أزرار النظام (رجوع، الشاشة الرئيسية، الحديثة، لوحة الإشعارات، الإعدادات السريعة، قائمة الطاقة، تقسيم
  الشاشة)، لمس نص على الشاشة، مسح الإشعارات.
- *المكالمات والرسائل*: إرسال رسالة نصية، الاتصال.
- *النظام*: إشعار، **أمر shell**، **أي إعداد للنظام** (`system`، `secure`، `global`)، بما يشمل إعدادات One UI الخاصة.
- *التسلسل*: الانتظار، تشغيل اختصار، تفعيل / إيقاف أتمتة.

**الاختصارات**: قوائم إجراءات بلا مشغِّل، تُشغَّل بنقرة واحدة من التطبيق أو من **الشاشة الرئيسية** أو من أحد **مربّعات
الإعدادات السريعة الثلاثة**.

**سجل** لكل ما تم تشغيله (مع نتيجة كل إجراء)، **تصدير / استيراد** بصيغة JSON، وواجهة بـ **23 لغة**.

## الأذونات خطوة بخطوة

لا يحتاج Flare إلى الروت أبدًا. يعرض كل إجراء الإذن الناقص، ويجمع تبويب **الأذونات** كل شيء.

1. **خيارات المطوّرين**: الإعدادات › حول الهاتف › معلومات البرنامج، اضغط *رقم الإصدار* 7 مرات.
2. **Shizuku**: ثبّت [Shizuku](https://shizuku.rikka.app/download/)، وفعّل *تصحيح الأخطاء اللاسلكي* في خيارات المطوّرين
   (أثناء الاتصال بشبكة Wi-Fi)، ثم في Shizuku: *البدء عبر تصحيح الأخطاء اللاسلكي* › *الاقتران*، وأدخل رمز الاقتران في
   الإشعار.
3. في Flare › **الأذونات**: *Shizuku › منح*، ثم **منح الكل**. يمنح Flare نفسه صلاحيات النظام الدائمة، وتسهيل الاستخدام،
   والوصول إلى الإشعارات، و«عدم الإزعاج»، والظهور فوق التطبيقات الأخرى، وعدم تقييد البطارية، وأذونات Android.
4. على Samsung: الإعدادات › التطبيقات › Flare › البطارية › **غير مقيّد**.

بعد إعادة التشغيل، يجب تشغيل Shizuku من جديد (الخطوة 2، دون اقتران جديد) لإجراءات Wi-Fi وبيانات الجوّال والبلوتوث ووضع
الطيران والوضع الداكن والأوامر. أما الباقي فيستمر في العمل بفضل صلاحيات النظام الدائمة.

من دون Shizuku، من حاسوب:

```sh
adb shell pm grant fr.apkfold.flare android.permission.WRITE_SECURE_SETTINGS
```

إذا ظهر تسهيل الاستخدام أو الوصول إلى الإشعارات باللون الرمادي (تطبيق مثبّت من خارج Play): معلومات التطبيق › ⋮ ›
*السماح بالإعدادات المحظورة*.

## مع Opus

يفتح مثال «وضع السيارة» الرابط `opus://flow` الذي يشغّل Flow في [Opus](https://github.com/apkangelo/opus). ويعمل إجراء
*تشغيل الموسيقى في تطبيق* مع أي مشغّل آخر أيضًا (Spotify وYouTube Music وDeezer…): عبر جلسة الوسائط في التطبيق، أو بإرسال
زر «تشغيل» إليه.

## البناء بنفسك

تحتاج إلى JDK 21 وAndroid SDK (أو Android Studio).

```sh
python3 scripts/i18n.py        # يولّد نصوص Android من i18n/*.json
cd android
./gradlew assembleRelease      # → android/app/build/outputs/apk/release/app-release.apk
```

مع كل تعديل، يتحقق GitHub Actions من الترجمات الـ23 ويبني ملف APK وينشره. ويشغّل workflow ثانٍ التطبيق في محاكي
Android 15، ويحاكي توصيل الشاحن للتأكد من استجابة المحرّك، ويلتقط لقطات الشاشة أعلاه.

## توقيع ملف APK

كل الإصدارات موقَّعة **بالمفتاح نفسه** (`signing/flare.jks`) لكي تُثبَّت التحديثات فوق الإصدار السابق. هذا المفتاح علني في
المستودع: لا تثبّت Flare إلا من هذا المستودع. لاستخدام مفتاح خاص، أضف في *Settings › Secrets › Actions* الأسرار
`FLARE_KEYSTORE_B64` (ملف ‎.jks بترميز base64) و`FLARE_KEYSTORE_PASSWORD` و`FLARE_KEY_ALIAS` و`FLARE_KEY_PASSWORD`.

## من المفيد معرفته

- تبقى الأتمتة والسجل والإعدادات **على الهاتف**. لا يملك Flare أي وصول إلى الإنترنت.
- تعمل أوامر shell بصلاحيات ADB الخاصة بـ Shizuku: لا تلصق إلا أوامر تفهمها.
- لا يمكن قراءة اسم شبكة Wi-Fi إلا بإذن الموقع (قاعدة في Android).

## بنية المستودع

| المجلد | المحتوى |
|---|---|
| `android/` | التطبيق (Kotlin وJetpack Compose): المحرّك في `core/` والخدمات في `service/` والشاشات في `ui/` |
| `i18n/` | نصوص الواجهة باللغات الـ23 |
| `scripts/` | توليد النصوص، الاختبار على المحاكي، المساعدة في البناء |
| `docs/` | لقطات الشاشة وملفات README المترجمة |
| `signing/` | مفتاح توقيع APK |
