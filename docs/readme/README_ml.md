# Flare

**Android**-നുള്ള ഓട്ടോമേഷനുകൾ. Apple-ന്റെ Shortcuts ആപ്പിന്റെ അതേ ആശയം, പക്ഷേ Samsung-ന്റെ "മോഡുകളും
ദിനചര്യകളും" എന്നതിനേക്കാൾ ശക്തം: **ഒരു ട്രിഗർ** (ബ്ലൂടൂത്ത് ഉപകരണം കണക്റ്റ് ചെയ്തു, Wi-Fi, ചാർജർ, സമയം, ആപ്പ്
തുറന്നു, ഫോൺ തുറന്നു…), ഐച്ഛികമായ **വ്യവസ്ഥകൾ**, തുടർന്ന് **ഒരു കൂട്ടം പ്രവർത്തനങ്ങൾ** (ക്രമീകരണങ്ങൾ, ആപ്പുകൾ,
സംഗീതം, കമാൻഡുകൾ…), കൂടാതെ ശരിയായ സമയത്ത് എല്ലാം പഴയപടിയാക്കുന്ന "അവസാനിക്കുമ്പോൾ" പ്രവർത്തനങ്ങളും.

ആപ്പിനൊപ്പമുള്ള ഉദാഹരണം: ഫോൺ ബ്ലൂടൂത്ത് വഴി കാറുമായി കണക്റ്റ് ചെയ്യുമ്പോൾ, Flare ശല്യപ്പെടുത്തരുത് ഓണാക്കുന്നു,
ശബ്ദം ക്രമീകരിക്കുന്നു, [Opus](https://github.com/apkangelo/opus)-ൽ സംഗീതം തുടങ്ങുന്നു, മാപ്‌സ് തുറക്കുന്നു;
വിച്ഛേദിക്കുമ്പോൾ സംഗീതം താൽക്കാലികമായി നിർത്തി ശല്യപ്പെടുത്തരുത് ഓഫാക്കുന്നു.

One UI ഉള്ള Galaxy Z Fold-നായി തയ്യാറാക്കിയത്: "ഫോൺ മടക്കി / തുറന്നു" ട്രിഗറുകൾ, കൂടാതെ Shizuku കാരണം റൂട്ട്
ആവശ്യമില്ല (ബൂട്ട്‌ലോഡർ അൺലോക്ക് ചെയ്യാൻ Samsung ഇനി അനുവദിക്കുന്നില്ല).

## ഡൗൺലോഡ്

**[Flare.apk](https://github.com/apkangelo/Flare/releases/latest/download/Flare.apk)** (Android 8 അല്ലെങ്കിൽ
പുതിയത്). ഫയൽ തുറന്ന്, ഈ ഉറവിടത്തിൽ നിന്നുള്ള ഇൻസ്റ്റാളേഷൻ അനുവദിച്ച്, *ഇൻസ്റ്റാൾ ചെയ്യുക* ടാപ്പ് ചെയ്യുക.
അപ്‌ഡേറ്റുകൾ ഓട്ടോമേഷനുകൾ നഷ്ടപ്പെടാതെ പഴയ പതിപ്പിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകും. എല്ലാ പതിപ്പുകളും
[*Releases*](https://github.com/apkangelo/Flare/releases) ടാബിലുണ്ട്; ഓരോ മാറ്റത്തിലും GitHub Actions അവ നിർമ്മിക്കുന്നു.

**ട്രിഗറുകൾ (27)**: ബ്ലൂടൂത്ത് ഉപകരണം കണക്റ്റ് / വിച്ഛേദം (പേരിന്റെ ഒരു ഭാഗം മതി: "Media Nav" "MEDIA-NAV"

ഓൺ / ഓഫ്, അൺലോക്ക്, **ഫോൺ മടക്കൽ / തുറക്കൽ**, ഹെഡ്‌ഫോൺ കണക്റ്റ് / ഊരൽ, നിശ്ചിത സമയവും ദിവസങ്ങളും, ഓരോ X

ലഭിക്കൽ, ഒരു സ്ഥലത്ത് എത്തൽ / വിടൽ.

**വ്യവസ്ഥകൾ (11)**: സമയപരിധി, ആഴ്ചയിലെ ദിവസങ്ങൾ, ബാറ്ററി, ചാർജ് ചെയ്യുന്നു, കണക്റ്റ് ചെയ്ത ബ്ലൂടൂത്ത് ഉപകരണം,
Wi-Fi നെറ്റ്‌വർക്ക്, മടക്കിയത് / തുറന്നത്, ഹെഡ്‌ഫോൺ, സ്ക്രീൻ ഓൺ, റിംഗർ മോഡ്, സ്ക്രീനിലെ ആപ്പ്.

**പ്രവർത്തനങ്ങൾ (40)**
- *കണക്ഷനുകൾ*: Wi-Fi, മൊബൈൽ ഡാറ്റ, ബ്ലൂടൂത്ത്, ഫ്ലൈറ്റ് മോഡ്, NFC, ലൊക്കേഷൻ (ഓൺ, ഓഫ്, മാറ്റുക).
- *സ്ക്രീൻ*: തെളിച്ചം, സ്ക്രീൻ ടൈംഔട്ട്, തിരിയൽ, ഡാർക്ക് മോഡ്, ചാർജിംഗിൽ സ്ക്രീൻ ഓൺ, പവർ സേവിംഗ്,
  ഫ്ലാഷ്‌ലൈറ്റ്, ലോക്ക്, സ്ക്രീൻ ഓണാക്കൽ, സ്ക്രീൻഷോട്ട്.
- *ശബ്ദവും മീഡിയയും*: റിംഗർ മോഡ്, ശല്യപ്പെടുത്തരുത്, ഓരോ തരത്തിന്റെയും ശബ്ദം, പ്ലേ / താൽക്കാലികമായി നിർത്തൽ /
  അടുത്തത്, നിശ്ചിത ആപ്പിൽ സംഗീതം തുടങ്ങൽ, വാചകം ഉറക്കെ വായിക്കൽ, വൈബ്രേഷൻ.
- *ആപ്പുകൾ*: ആപ്പ്, ലിങ്ക് അല്ലെങ്കിൽ ഡീപ് ലിങ്ക് തുറക്കൽ (`opus://flow`, `tel:`, `geo:`…), മാപ്‌സ് നാവിഗേഷൻ,
  നിർബന്ധിതമായി നിർത്തൽ, ക്രമീകരണ പേജ് തുറക്കൽ, intent അയയ്ക്കൽ.
- *സ്ക്രീൻ നിയന്ത്രണം*: സിസ്റ്റം ബട്ടണുകൾ (മടങ്ങുക, ഹോം, സമീപകാലം, അറിയിപ്പ് പാനൽ, ദ്രുത ക്രമീകരണങ്ങൾ, പവർ മെനു,
  സ്ക്രീൻ വിഭജനം), സ്ക്രീനിലെ വാചകം ടാപ്പ് ചെയ്യൽ, അറിയിപ്പുകൾ മായ്ക്കൽ.
- *കോളുകളും SMS-ഉം*: SMS അയയ്ക്കൽ, വിളിക്കൽ.
- *സിസ്റ്റം*: അറിയിപ്പ്, **shell കമാൻഡ്**, **ഏത് സിസ്റ്റം ക്രമീകരണവും** (`system`, `secure`, `global`), One UI-യുടെ
  സ്വന്തം ക്രമീകരണങ്ങൾ ഉൾപ്പെടെ.
- *ക്രമം*: കാത്തിരിക്കൽ, കുറുക്കുവഴി പ്രവർത്തിപ്പിക്കൽ, ഓട്ടോമേഷൻ ഓൺ / ഓഫ് ചെയ്യൽ.

**കുറുക്കുവഴികൾ**: ട്രിഗറില്ലാത്ത പ്രവർത്തന പട്ടികകൾ; ആപ്പിൽ നിന്നോ **ഹോം സ്ക്രീനിൽ** നിന്നോ **3 ദ്രുത ക്രമീകരണ
ടൈലുകളിൽ** ഒന്നിൽ നിന്നോ ഒറ്റ ടാപ്പിൽ പ്രവർത്തിക്കും.

പ്രവർത്തിച്ച എല്ലാറ്റിന്റെയും **ലോഗ്** (ഓരോ പ്രവർത്തനത്തിന്റെയും ഫലത്തോടെ), JSON **എക്സ്പോർട്ട് / ഇമ്പോർട്ട്**,
**23 ഭാഷകളിൽ** ഇന്റർഫേസ്.

## അനുമതികൾ, ഘട്ടം ഘട്ടമായി

Flare-ന് ഒരിക്കലും റൂട്ട് ആവശ്യമില്ല. ഓരോ പ്രവർത്തനവും കുറവുള്ള ആക്‌സസ് കാണിക്കും, **അനുമതികൾ** ടാബിൽ എല്ലാം
ഒരുമിച്ചുണ്ട്.

1. **ഡെവലപ്പർ ഓപ്ഷനുകൾ**: ക്രമീകരണങ്ങൾ › ഫോണിനെക്കുറിച്ച് › സോഫ്റ്റ്‌വെയർ വിവരം, *ബിൽഡ് നമ്പർ* 7 തവണ ടാപ്പ്
   ചെയ്യുക.
2. **Shizuku**: [Shizuku](https://shizuku.rikka.app/download/) ഇൻസ്റ്റാൾ ചെയ്ത്, ഡെവലപ്പർ ഓപ്ഷനുകളിൽ *വയർലെസ്
   ഡീബഗ്ഗിംഗ്* ഓണാക്കുക (Wi-Fi-യിൽ), തുടർന്ന് Shizuku-ൽ: *വയർലെസ് ഡീബഗ്ഗിംഗ് വഴി ആരംഭിക്കുക* › *ജോടിയാക്കുക*,
   അറിയിപ്പിൽ ജോടിയാക്കൽ കോഡ് നൽകുക.
3. Flare › **അനുമതികൾ**: *Shizuku › നൽകുക*, തുടർന്ന് **എല്ലാം നൽകുക**. സ്ഥിര സിസ്റ്റം അവകാശങ്ങൾ, പ്രവേശനക്ഷമത,
   അറിയിപ്പ് ആക്‌സസ്, ശല്യപ്പെടുത്തരുത്, മറ്റ് ആപ്പുകൾക്ക് മുകളിൽ കാണിക്കൽ, ബാറ്ററി നിയന്ത്രണമില്ലായ്മ, Android
   അനുമതികൾ എന്നിവ Flare സ്വയം നൽകും.
4. Samsung-ൽ: ക്രമീകരണങ്ങൾ › ആപ്പുകൾ › Flare › ബാറ്ററി › **നിയന്ത്രണമില്ലാത്തത്**.

റീസ്റ്റാർട്ടിന് ശേഷം Wi-Fi, മൊബൈൽ ഡാറ്റ, ബ്ലൂടൂത്ത്, ഫ്ലൈറ്റ് മോഡ്, ഡാർക്ക് മോഡ്, കമാൻഡുകൾ എന്നീ പ്രവർത്തനങ്ങൾക്കായി
Shizuku വീണ്ടും ആരംഭിക്കണം (ഘട്ടം 2, വീണ്ടും ജോടിയാക്കേണ്ടതില്ല). ബാക്കിയെല്ലാം സ്ഥിര സിസ്റ്റം അവകാശങ്ങൾ കാരണം
പ്രവർത്തിക്കും.

Shizuku ഇല്ലാതെ, ഒരു കമ്പ്യൂട്ടറിൽ നിന്ന്:

```sh
adb shell pm grant fr.apkfold.flare android.permission.WRITE_SECURE_SETTINGS
```

പ്രവേശനക്ഷമതയോ അറിയിപ്പ് ആക്‌സസോ ചാരനിറത്തിലാണെങ്കിൽ (Play Store-ന് പുറത്തുനിന്ന് ഇൻസ്റ്റാൾ ചെയ്ത ആപ്പ്): ആപ്പ്
വിവരം › ⋮ › *നിയന്ത്രിത ക്രമീകരണങ്ങൾ അനുവദിക്കുക*.

## Opus-നൊപ്പം

"കാർ മോഡ്" ഉദാഹരണം `opus://flow` തുറക്കുന്നു, അത് [Opus](https://github.com/apkangelo/opus)-ലെ Flow ആരംഭിക്കുന്നു.
*ഒരു ആപ്പിൽ സംഗീതം പ്ലേ ചെയ്യുക* എന്ന പ്രവർത്തനം മറ്റേത് പ്ലെയറിലും (Spotify, YouTube Music, Deezer…) പ്രവർത്തിക്കും:
ആപ്പിന്റെ മീഡിയ സെഷൻ വഴിയോ "പ്ലേ" കീ അയച്ചോ.

## സ്വയം നിർമ്മിക്കാൻ

JDK 21-ഉം Android SDK-യും (അല്ലെങ്കിൽ Android Studio) ആവശ്യമാണ്.

```sh
python3 scripts/i18n.py        # i18n/*.json-ൽ നിന്ന് Android സ്ട്രിംഗുകൾ നിർമ്മിക്കുന്നു
cd android
./gradlew assembleRelease      # → android/app/build/outputs/apk/release/app-release.apk
```

ഓരോ മാറ്റത്തിലും GitHub Actions 23 വിവർത്തനങ്ങളും പരിശോധിച്ച് APK നിർമ്മിച്ച് പ്രസിദ്ധീകരിക്കുന്നു. രണ്ടാമത്തെ
workflow ആപ്പിനെ Android 15 എമുലേറ്ററിൽ പ്രവർത്തിപ്പിക്കുകയും, എഞ്ചിൻ പ്രതികരിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കാൻ ചാർജർ
കണക്റ്റ് ചെയ്യുന്നത് അനുകരിക്കുകയും, മുകളിലെ സ്ക്രീൻഷോട്ടുകൾ എടുക്കുകയും ചെയ്യുന്നു.

## APK ഒപ്പ്

അപ്‌ഡേറ്റുകൾ പഴയതിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകാൻ എല്ലാ പതിപ്പുകളും **ഒരേ കീ** (`signing/flare.jks`) ഉപയോഗിച്ചാണ്
ഒപ്പിടുന്നത്. ഈ കീ റിപ്പോസിറ്ററിയിൽ പൊതുവാണ്: Flare ഈ റിപ്പോസിറ്ററിയിൽ നിന്ന് മാത്രം ഇൻസ്റ്റാൾ ചെയ്യുക. സ്വകാര്യ
കീ ഉപയോഗിക്കാൻ, *Settings › Secrets › Actions*-ൽ `FLARE_KEYSTORE_B64` (base64-ലുള്ള .jks ഫയൽ),
`FLARE_KEYSTORE_PASSWORD`, `FLARE_KEY_ALIAS`, `FLARE_KEY_PASSWORD` എന്നീ secrets ചേർക്കുക.

## അറിഞ്ഞിരിക്കേണ്ടവ

- ഓട്ടോമേഷനുകളും ലോഗും ക്രമീകരണങ്ങളും **ഫോണിൽ തന്നെ** നിൽക്കും. Flare-ന് ഇന്റർനെറ്റ് ആക്‌സസ് ഇല്ല.
- shell കമാൻഡുകൾ Shizuku-ന്റെ ADB അവകാശങ്ങളോടെയാണ് പ്രവർത്തിക്കുന്നത്: മനസ്സിലാകുന്ന കമാൻഡുകൾ മാത്രം ഒട്ടിക്കുക.
- ലൊക്കേഷൻ അനുമതിയില്ലാതെ Wi-Fi നെറ്റ്‌വർക്കിന്റെ പേര് വായിക്കാനാവില്ല (Android നിയമം).

## റിപ്പോസിറ്ററി ഘടന

| ഫോൾഡർ | ഉള്ളടക്കം |
|---|---|
| `android/` | ആപ്പ് (Kotlin, Jetpack Compose): എഞ്ചിൻ `core/`-ൽ, സേവനങ്ങൾ `service/`-ൽ, സ്ക്രീനുകൾ `ui/`-ൽ |
