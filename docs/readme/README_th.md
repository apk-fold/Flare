# Flare

แอประบบอัตโนมัติสำหรับ **Android** ในแนวเดียวกับแอปคำสั่งลัดของ Apple แต่ทำได้มากกว่า "โหมดและรูทีน" ของ Samsung:
**ตัวกระตุ้น** (เชื่อมต่ออุปกรณ์บลูทูธ, Wi-Fi, ที่ชาร์จ, เวลา, เปิดแอป, กางโทรศัพท์…), **เงื่อนไข** ที่จะใส่หรือไม่ก็ได้
แล้วตามด้วย **ชุดการทำงาน** (การตั้งค่า แอป เพลง คำสั่ง…) และการทำงาน "เมื่อสิ้นสุด" ที่คืนค่าทุกอย่างในเวลาที่เหมาะสม

ตัวอย่างที่มากับแอป: เมื่อโทรศัพท์เชื่อมต่อบลูทูธกับรถ Flare จะเปิดห้ามรบกวน ปรับระดับเสียง เล่นเพลงใน
[Opus](https://github.com/apkangelo/opus) และเปิดแผนที่ เมื่อตัดการเชื่อมต่อ จะหยุดเพลงชั่วคราวและปิดห้ามรบกวน

ออกแบบมาสำหรับ Galaxy Z Fold ที่ใช้ One UI: มีตัวกระตุ้น "พับ / กางโทรศัพท์" และไม่ต้องรูท (Samsung ไม่อนุญาตให้ปลดล็อก
bootloader แล้ว) ด้วย Shizuku

## Flare ทำอะไรได้บ้าง

**ตัวกระตุ้น (27)**: เชื่อมต่อ / ตัดการเชื่อมต่ออุปกรณ์บลูทูธ (ใส่บางส่วนของชื่อก็พอ: "Media Nav" จะรู้จัก "MEDIA-NAV"),
เชื่อมต่อ / ตัด Wi-Fi, โหมดเครื่องบิน, เสียบ / ถอดที่ชาร์จ, ระดับแบตเตอรี่, เปิดเครื่อง, หน้าจอเปิด / ปิด, ปลดล็อก,
**พับ / กางโทรศัพท์**, เสียบ / ถอดหูฟัง, เวลาและวันที่กำหนด, ทุก X นาที, เปิด / ปิดแอป, ได้รับการแจ้งเตือน (แอป ข้อความ),
สายเรียกเข้า / เริ่มโทร / วางสาย, ได้รับ SMS, มาถึง / ออกจากสถานที่

**เงื่อนไข (11)**: ช่วงเวลา, วันในสัปดาห์, แบตเตอรี่, กำลังชาร์จ, เชื่อมต่ออุปกรณ์บลูทูธอยู่, เครือข่าย Wi-Fi, พับ / กาง,
หูฟัง, หน้าจอเปิด, โหมดเสียงเรียกเข้า, แอปบนหน้าจอ

**การทำงาน (40)**
- *การเชื่อมต่อ*: Wi-Fi, อินเทอร์เน็ตมือถือ, บลูทูธ, โหมดเครื่องบิน, NFC, ตำแหน่ง (เปิด ปิด สลับ)
- *หน้าจอ*: ความสว่าง, ระยะหมดเวลาหน้าจอ, หมุนอัตโนมัติ, โหมดมืด, เปิดหน้าจอค้างขณะชาร์จ, ประหยัดพลังงาน, ไฟฉาย, ล็อก,
  เปิดหน้าจอ, จับภาพหน้าจอ
- *เสียงและสื่อ*: โหมดเสียงเรียกเข้า, ห้ามรบกวน, ระดับเสียงแต่ละประเภท, เล่น / หยุดชั่วคราว / ถัดไป, เล่นเพลงในแอปที่ระบุ,
  อ่านข้อความออกเสียง, สั่น
- *แอป*: เปิดแอป ลิงก์ หรือดีปลิงก์ (`opus://flow`, `tel:`, `geo:`…), นำทางด้วยแผนที่, บังคับหยุด, เปิดหน้าการตั้งค่า,
  ส่ง intent
- *ควบคุมหน้าจอ*: ปุ่มระบบ (กลับ หน้าหลัก แอปล่าสุด แผงการแจ้งเตือน การตั้งค่าด่วน เมนูเปิด/ปิดเครื่อง แยกหน้าจอ),
  แตะข้อความบนหน้าจอ, ล้างการแจ้งเตือน
- *การโทรและ SMS*: ส่ง SMS, โทรออก
- *ระบบ*: การแจ้งเตือน, **คำสั่ง shell**, **การตั้งค่าระบบใดก็ได้** (`system`, `secure`, `global`) ซึ่งรวมถึงการตั้งค่า
  เฉพาะของ One UI
- *ลำดับการทำงาน*: รอ, เรียกใช้ทางลัด, เปิด / ปิดระบบอัตโนมัติ

**ทางลัด**: รายการการทำงานที่ไม่มีตัวกระตุ้น เรียกใช้ได้ด้วยการแตะครั้งเดียวจากแอป จาก **หน้าจอหลัก** หรือจาก
**ไทล์การตั้งค่าด่วน 3 อัน** อันใดอันหนึ่ง

**บันทึก** ทุกอย่างที่ทำงาน (พร้อมผลของแต่ละการทำงาน), **ส่งออก / นำเข้า** เป็น JSON, หน้าตาแอป **23 ภาษา**

## การให้สิทธิ์ทีละขั้น

Flare ไม่ต้องใช้รูทเลย แต่ละการทำงานจะบอกว่าขาดสิทธิ์อะไร และแท็บ **สิทธิ์** รวมทุกอย่างไว้

1. **ตัวเลือกสำหรับนักพัฒนา**: การตั้งค่า › เกี่ยวกับโทรศัพท์ › ข้อมูลซอฟต์แวร์ แตะ *หมายเลขรุ่นสร้าง* 7 ครั้ง
2. **Shizuku**: ติดตั้ง [Shizuku](https://shizuku.rikka.app/download/) เปิด *การแก้ไขข้อบกพร่องแบบไร้สาย*
   ในตัวเลือกสำหรับนักพัฒนา (ขณะเชื่อมต่อ Wi-Fi) จากนั้นใน Shizuku: *เริ่มผ่านการแก้ไขข้อบกพร่องแบบไร้สาย* › *จับคู่*
   แล้วพิมพ์รหัสจับคู่ในการแจ้งเตือน
3. ใน Flare › **สิทธิ์**: *Shizuku › ให้สิทธิ์* แล้วแตะ **ให้สิทธิ์ทั้งหมด** Flare จะให้สิทธิ์ตัวเองทั้งสิทธิ์ระบบถาวร
   การเข้าถึง สิทธิ์เข้าถึงการแจ้งเตือน ห้ามรบกวน การแสดงทับแอปอื่น การไม่จำกัดแบตเตอรี่ และสิทธิ์ของ Android
4. บน Samsung: การตั้งค่า › แอปพลิเคชัน › Flare › แบตเตอรี่ › **ไม่จำกัด**

หลังรีสตาร์ท ต้องเริ่ม Shizuku ใหม่ (ขั้นที่ 2 โดยไม่ต้องจับคู่ใหม่) สำหรับการทำงาน Wi-Fi, อินเทอร์เน็ตมือถือ, บลูทูธ,
โหมดเครื่องบิน, โหมดมืด และคำสั่ง ส่วนที่เหลือยังทำงานต่อได้ด้วยสิทธิ์ระบบถาวร

หากไม่มี Shizuku ให้ใช้คอมพิวเตอร์:

```sh
adb shell pm grant fr.apkfold.flare android.permission.WRITE_SECURE_SETTINGS
```

หากการเข้าถึงหรือสิทธิ์เข้าถึงการแจ้งเตือนเป็นสีเทา (แอปที่ติดตั้งนอก Play Store): ข้อมูลแอป › ⋮ ›
*อนุญาตการตั้งค่าที่จำกัด*

## ใช้กับ Opus

ตัวอย่าง "โหมดรถยนต์" จะเปิด `opus://flow` ซึ่งเริ่ม Flow ใน [Opus](https://github.com/apkangelo/opus) การทำงาน
*เล่นเพลงในแอป* ใช้ได้กับเครื่องเล่นอื่นด้วย (Spotify, YouTube Music, Deezer…) โดยผ่านเซสชันสื่อของแอป
หรือส่งปุ่ม "เล่น" ให้แอป

## สร้างเอง

ต้องมี JDK 21 และ Android SDK (หรือ Android Studio)

```sh
python3 scripts/i18n.py        # สร้างข้อความ Android จาก i18n/*.json
cd android
./gradlew assembleRelease      # → android/app/build/outputs/apk/release/app-release.apk
```

ทุกครั้งที่มีการแก้ไข GitHub Actions จะตรวจคำแปล 23 ภาษา สร้าง และเผยแพร่ APK อีก workflow หนึ่งจะรันแอปในอีมูเลเตอร์
Android 15 จำลองการเสียบที่ชาร์จเพื่อตรวจว่าระบบตอบสนอง และถ่ายภาพหน้าจอด้านบน

## การเซ็น APK

ทุกเวอร์ชันเซ็นด้วย **คีย์เดียวกัน** (`signing/flare.jks`) เพื่อให้ติดตั้งอัปเดตทับได้ คีย์นี้เปิดเผยในคลัง: ติดตั้ง Flare
จากคลังนี้เท่านั้น หากต้องการใช้คีย์ส่วนตัว ให้เพิ่ม secrets `FLARE_KEYSTORE_B64` (ไฟล์ .jks แบบ base64),
`FLARE_KEYSTORE_PASSWORD`, `FLARE_KEY_ALIAS` และ `FLARE_KEY_PASSWORD` ใน *Settings › Secrets › Actions*

## ควรรู้

- ระบบอัตโนมัติ บันทึก และการตั้งค่าอยู่ **ในโทรศัพท์** เท่านั้น Flare ไม่มีสิทธิ์เข้าถึงอินเทอร์เน็ต
- คำสั่ง shell ทำงานด้วยสิทธิ์ ADB ของ Shizuku: วางเฉพาะคำสั่งที่คุณเข้าใจ
- ชื่อเครือข่าย Wi-Fi อ่านได้เฉพาะเมื่อมีสิทธิ์ตำแหน่ง (กฎของ Android)
