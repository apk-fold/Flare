# Flare

Автоматизації для **Android** у дусі застосунку «Команди» від Apple, але потужніші за «Режими та підпрограми» Samsung:
**тригер** (під'єднано Bluetooth-пристрій, Wi-Fi, зарядка, час, відкрито застосунок, телефон розкрито…), необов'язкові
**умови**, далі **ланцюжок дій** (налаштування, застосунки, музика, команди…), а також дії «коли це закінчиться», які
в потрібну мить усе повертають назад.

Приклад у комплекті: коли телефон під'єднується до авто через Bluetooth, Flare вмикає «Не турбувати», виставляє
гучність, запускає музику в [Opus](https://github.com/apkangelo/opus) і відкриває Карти; після від'єднання ставить
музику на паузу й вимикає «Не турбувати».

Створено для Galaxy Z Fold на One UI: тригери «телефон складено / розкрито», і жодного root (Samsung більше не дозволяє
розблокувати завантажувач) — завдяки Shizuku.

## Завантажити

**[Flare.apk](https://github.com/apkangelo/Flare/releases/latest/download/Flare.apk)** (Android 8 або новіший).
Відкрийте файл, дозвольте встановлення з цього джерела й натисніть *Встановити*. Оновлення встановлюються поверх без
втрати автоматизацій. Усі версії — на вкладці [*Releases*](https://github.com/apkangelo/Flare/releases), їх збирає
GitHub Actions після кожної зміни.

## Що вміє Flare

**Тригери (27)**: Bluetooth-пристрій під'єднано / від'єднано (досить частини назви: «Media Nav» знайде «MEDIA-NAV»),
Wi-Fi під'єднано / від'єднано, режим польоту, зарядку під'єднано / від'єднано, рівень заряду, увімкнення телефона,
екран увімкнено / вимкнено, розблокування, **телефон складено / розкрито**, навушники під'єднано / від'єднано, заданий
час і дні, кожні X хвилин, застосунок відкрито / закрито, отримано сповіщення (застосунок, текст), дзвінок вхідний /
почався / завершено, отримано SMS, прибуття в місце / вихід.

**Умови (11)**: проміжок часу, дні тижня, заряд, заряджання, під'єднаний Bluetooth-пристрій, мережа Wi-Fi, складено /
розкрито, навушники, екран увімкнено, режим дзвінка, застосунок на екрані.

**Дії (40)**
- *Підключення*: Wi-Fi, мобільні дані, Bluetooth, режим польоту, NFC, геолокація (увімк., вимк., перемкнути).
- *Екран*: яскравість, тайм-аут екрана, обертання, темна тема, не вимикати під час заряджання, енергозбереження,
  ліхтарик, блокування, увімкнути екран, знімок екрана.
- *Звук і медіа*: режим дзвінка, «Не турбувати», гучність кожного потоку, відтворення / пауза / наступний, увімкнути
  музику в потрібному застосунку, прочитати текст уголос, вібрація.
- *Застосунки*: відкрити застосунок, посилання чи deep link (`opus://flow`, `tel:`, `geo:`…), навігація в Картах,
  примусова зупинка, відкрити сторінку налаштувань, надіслати intent.
- *Керування екраном*: системні кнопки (назад, головний екран, нещодавні, панель сповіщень, швидкі налаштування, меню
  живлення, розділений екран), торкнутися тексту на екрані, очистити сповіщення.
- *Дзвінки й SMS*: надіслати SMS, зателефонувати.
- *Система*: сповіщення, **команда shell**, **будь-яке системне налаштування** (`system`, `secure`, `global`) — це
  охоплює й власні налаштування One UI.
- *Хід виконання*: зачекати, запустити ярлик, увімкнути / вимкнути автоматизацію.

**Ярлики**: списки дій без тригера, запускаються одним дотиком із застосунку, з **головного екрана** або з однієї
з **3 плиток швидких налаштувань**.

**Журнал** усіх запусків (з результатом кожної дії), **експорт / імпорт** у JSON, інтерфейс **23 мовами**.

## Доступ крок за кроком

Flare ніколи не потрібен root. Кожна дія показує, якого доступу їй бракує, а вкладка **Доступ** збирає все разом.

1. **Параметри розробника**: Налаштування › Відомості про телефон › Відомості про ПЗ, 7 разів торкніться *Номер
   збірки*.
2. **Shizuku**: встановіть [Shizuku](https://shizuku.rikka.app/download/), увімкніть *Бездротове налагодження*
   в параметрах розробника (у Wi-Fi), потім у Shizuku: *Запуск через бездротове налагодження* › *Сполучення* і введіть
   код сполучення у сповіщенні.
3. У Flare › **Доступ**: *Shizuku › Надати*, потім **Надати все**. Flare сам надає собі постійні системні права,
   спеціальні можливості, доступ до сповіщень, «Не турбувати», показ поверх інших застосунків, відсутність обмежень
   батареї та дозволи Android.
4. На Samsung: Налаштування › Програми › Flare › Акумулятор › **Без обмежень**.

Після перезавантаження Shizuku треба запустити знову (крок 2, без повторного сполучення) для дій Wi-Fi, мобільні дані,
Bluetooth, режим польоту, темна тема й команди. Решта працює далі завдяки постійним системним правам.

Без Shizuku, з комп'ютера:

```sh
adb shell pm grant fr.apkfold.flare android.permission.WRITE_SECURE_SETTINGS
```

Якщо спеціальні можливості чи доступ до сповіщень неактивні (застосунок встановлено не з Play Маркету): Про
застосунок › ⋮ › *Дозволити обмежені налаштування*.

## З Opus

Приклад «Режим авто» відкриває `opus://flow`, що запускає Flow в [Opus](https://github.com/apkangelo/opus). Дія
*Увімкнути музику в застосунку* працює й з будь-яким іншим плеєром (Spotify, YouTube Music, Deezer…): через
медіасеанс застосунку або надсиланням клавіші «відтворення».

## Зібрати самостійно

Потрібні JDK 21 та Android SDK (або Android Studio).

```sh
python3 scripts/i18n.py        # генерує рядки Android з i18n/*.json
cd android
./gradlew assembleRelease      # → android/app/build/outputs/apk/release/app-release.apk
```

Після кожної зміни GitHub Actions перевіряє 23 переклади, збирає й публікує APK. Другий workflow запускає застосунок
в емуляторі Android 15, імітує під'єднання зарядки, щоб перевірити реакцію рушія, і робить знімки екрана вище.

## Підпис APK

Усі версії підписано **одним ключем** (`signing/flare.jks`), щоб оновлення встановлювалися поверх. Ключ відкритий
у репозиторії: встановлюйте Flare лише звідси. Для власного закритого ключа додайте в *Settings › Secrets › Actions*
секрети `FLARE_KEYSTORE_B64` (файл .jks у base64), `FLARE_KEYSTORE_PASSWORD`, `FLARE_KEY_ALIAS`
і `FLARE_KEY_PASSWORD`.

## Корисно знати

- Автоматизації, журнал і налаштування залишаються **на телефоні**. Flare не має доступу до інтернету.
- Команди shell виконуються з правами ADB від Shizuku: вставляйте лише зрозумілі вам команди.
- Назву мережі Wi-Fi можна прочитати лише з дозволом на геолокацію (правило Android).
