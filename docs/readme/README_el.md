# Flare

Αυτοματισμοί για **Android**, στο πνεύμα της εφαρμογής Συντομεύσεις της Apple, αλλά πιο πλήρεις από τις «Λειτουργίες
και ρουτίνες» της Samsung: **ένα έναυσμα** (συνδεδεμένη συσκευή Bluetooth, Wi-Fi, φορτιστής, ώρα, ανοιχτή εφαρμογή,
ανοιγμένο τηλέφωνο…), προαιρετικές **συνθήκες**, μετά **μια σειρά ενεργειών** (ρυθμίσεις, εφαρμογές, μουσική,
εντολές…), καθώς και ενέργειες «όταν σταματήσει» που τα επαναφέρουν όλα τη σωστή στιγμή.

Παράδειγμα μέσα στην εφαρμογή: όταν το τηλέφωνο συνδέεται με Bluetooth στο αυτοκίνητο, το Flare ενεργοποιεί το «Μην
ενοχλείτε», ρυθμίζει την ένταση, ξεκινά τη μουσική στο [Opus](https://github.com/apkangelo/opus) και ανοίγει τους
Χάρτες· στην αποσύνδεση, κάνει παύση στη μουσική και απενεργοποιεί το «Μην ενοχλείτε».

Φτιαγμένο για το Galaxy Z Fold με One UI: εναύσματα «τηλέφωνο διπλωμένο / ανοιχτό», και χωρίς root (η Samsung δεν
επιτρέπει πια το ξεκλείδωμα του bootloader) χάρη στο Shizuku.

## Λήψη

**[Flare.apk](https://github.com/apkangelo/Flare/releases/latest/download/Flare.apk)** (Android 8 ή νεότερο). Άνοιξε
το αρχείο, επίτρεψε την εγκατάσταση από αυτή την πηγή και πάτησε *Εγκατάσταση*. Οι ενημερώσεις εγκαθίστανται από πάνω
χωρίς να χαθούν οι αυτοματισμοί σου. Όλες οι εκδόσεις βρίσκονται στην καρτέλα
[*Releases*](https://github.com/apkangelo/Flare/releases) και χτίζονται από το GitHub Actions σε κάθε αλλαγή.

## Τι κάνει το Flare

**Εναύσματα (27)**: συσκευή Bluetooth συνδέθηκε / αποσυνδέθηκε (αρκεί μέρος του ονόματος: το «Media Nav» αναγνωρίζει
το «MEDIA-NAV»), Wi-Fi συνδέθηκε / αποσυνδέθηκε, λειτουργία πτήσης, φορτιστής συνδέθηκε / αποσυνδέθηκε, επίπεδο
μπαταρίας, εκκίνηση τηλεφώνου, οθόνη αναμμένη / σβηστή, ξεκλείδωμα, **τηλέφωνο διπλωμένο / ανοιχτό**, ακουστικά
συνδέθηκαν / αποσυνδέθηκαν, συγκεκριμένη ώρα και ημέρες, κάθε X λεπτά, εφαρμογή άνοιξε / έκλεισε, λήψη ειδοποίησης
(εφαρμογή, κείμενο), κλήση εισερχόμενη / ξεκίνησε / τελείωσε, λήψη SMS, άφιξη σε / αναχώρηση από τοποθεσία.

**Συνθήκες (11)**: χρονικό διάστημα, ημέρες της εβδομάδας, μπαταρία, φόρτιση, συνδεδεμένη συσκευή Bluetooth, δίκτυο
Wi-Fi, διπλωμένο / ανοιχτό, ακουστικά, αναμμένη οθόνη, λειτουργία κουδουνίσματος, εφαρμογή στην οθόνη.

**Ενέργειες (40)**
- *Συνδέσεις*: Wi-Fi, δεδομένα κινητής, Bluetooth, λειτουργία πτήσης, NFC, τοποθεσία (ενεργό, ανενεργό, εναλλαγή).
- *Οθόνη*: φωτεινότητα, λήξη χρόνου οθόνης, περιστροφή, σκούρο θέμα, αναμμένη κατά τη φόρτιση, εξοικονόμηση ενέργειας,
  φακός, κλείδωμα, άναμμα οθόνης, στιγμιότυπο οθόνης.
- *Ήχος και πολυμέσα*: λειτουργία κουδουνίσματος, «Μην ενοχλείτε», ένταση κάθε ροής, αναπαραγωγή / παύση / επόμενο,
  μουσική σε συγκεκριμένη εφαρμογή, ανάγνωση κειμένου φωναχτά, δόνηση.
- *Εφαρμογές*: άνοιγμα εφαρμογής, συνδέσμου ή deep link (`opus://flow`, `tel:`, `geo:`…), πλοήγηση στους Χάρτες,
  αναγκαστική διακοπή, άνοιγμα σελίδας ρυθμίσεων, αποστολή intent.
- *Έλεγχος οθόνης*: κουμπιά συστήματος (πίσω, αρχική, πρόσφατες, πλαίσιο ειδοποιήσεων, γρήγορες ρυθμίσεις, μενού
  λειτουργίας, διαχωρισμός οθόνης), άγγιγμα κειμένου στην οθόνη, διαγραφή ειδοποιήσεων.
- *Κλήσεις και SMS*: αποστολή SMS, κλήση.
- *Σύστημα*: ειδοποίηση, **εντολή shell**, **οποιαδήποτε ρύθμιση συστήματος** (`system`, `secure`, `global`), που
  καλύπτει και τις ρυθμίσεις του One UI.
- *Ροή*: αναμονή, εκτέλεση συντόμευσης, ενεργοποίηση / απενεργοποίηση αυτοματισμού.

**Συντομεύσεις**: λίστες ενεργειών χωρίς έναυσμα, που ξεκινούν με ένα πάτημα από την εφαρμογή, από την **αρχική οθόνη**
ή από ένα από τα **3 πλακίδια γρήγορων ρυθμίσεων**.

**Ιστορικό** όλων των εκτελέσεων (με το αποτέλεσμα κάθε ενέργειας), **εξαγωγή / εισαγωγή** σε JSON, περιβάλλον σε
**23 γλώσσες**.

## Οι άδειες, βήμα βήμα

Το Flare δεν χρειάζεται ποτέ root. Κάθε ενέργεια δείχνει ποια πρόσβαση της λείπει, και η καρτέλα **Άδειες** τα
συγκεντρώνει όλα.

1. **Επιλογές προγραμματιστή**: Ρυθμίσεις › Σχετικά με το τηλέφωνο › Πληροφορίες λογισμικού, πάτησε 7 φορές τον
   *Αριθμό έκδοσης*.
2. **Shizuku**: εγκατάστησε το [Shizuku](https://shizuku.rikka.app/download/), ενεργοποίησε τον *Ασύρματο εντοπισμό
   σφαλμάτων* στις επιλογές προγραμματιστή (σε Wi-Fi) και μετά στο Shizuku: *Έναρξη μέσω ασύρματου εντοπισμού
   σφαλμάτων* › *Σύζευξη*, και πληκτρολόγησε τον κωδικό σύζευξης στην ειδοποίηση.
3. Στο Flare › **Άδειες**: *Shizuku › Παραχώρηση*, μετά **Παραχώρηση όλων**. Το Flare παραχωρεί μόνο του τα μόνιμα
   δικαιώματα συστήματος, την προσβασιμότητα, την πρόσβαση στις ειδοποιήσεις, το «Μην ενοχλείτε», την εμφάνιση πάνω
   από άλλες εφαρμογές, την απουσία περιορισμών μπαταρίας και τις άδειες του Android.
4. Σε Samsung: Ρυθμίσεις › Εφαρμογές › Flare › Μπαταρία › **Χωρίς περιορισμούς**.

Μετά από επανεκκίνηση, το Shizuku πρέπει να ξεκινήσει ξανά (βήμα 2, χωρίς νέα σύζευξη) για τις ενέργειες Wi-Fi,
δεδομένα κινητής, Bluetooth, λειτουργία πτήσης, σκούρο θέμα και εντολές. Όλα τα άλλα συνεχίζουν να λειτουργούν χάρη
στα μόνιμα δικαιώματα συστήματος.

Χωρίς Shizuku, από υπολογιστή:

```sh
adb shell pm grant fr.apkfold.flare android.permission.WRITE_SECURE_SETTINGS
```

Αν η προσβασιμότητα ή η πρόσβαση στις ειδοποιήσεις είναι γκρι (εφαρμογή εκτός Play Store): Πληροφορίες εφαρμογής › ⋮ ›
*Να επιτρέπονται οι περιορισμένες ρυθμίσεις*.

## Με το Opus

Το παράδειγμα «Λειτουργία αυτοκινήτου» ανοίγει το `opus://flow`, που ξεκινά το Flow του
[Opus](https://github.com/apkangelo/opus). Η ενέργεια *Μουσική σε μια εφαρμογή* λειτουργεί και με κάθε άλλη εφαρμογή
αναπαραγωγής (Spotify, YouTube Music, Deezer…): περνά από τη συνεδρία πολυμέσων της εφαρμογής ή της στέλνει το κουμπί
«αναπαραγωγή».

## Δημιουργία από τον κώδικα

Χρειάζεσαι JDK 21 και Android SDK (ή Android Studio).

```sh
python3 scripts/i18n.py        # δημιουργεί τα κείμενα Android από το i18n/*.json
cd android
./gradlew assembleRelease      # → android/app/build/outputs/apk/release/app-release.apk
```

Σε κάθε αλλαγή, το GitHub Actions ελέγχει τις 23 μεταφράσεις, χτίζει και δημοσιεύει το APK. Ένα δεύτερο workflow τρέχει
την εφαρμογή σε εξομοιωτή Android 15, προσομοιώνει τη σύνδεση φορτιστή για να ελέγξει ότι η μηχανή αντιδρά και τραβά
τα παραπάνω στιγμιότυπα.

## Υπογραφή του APK

Όλες οι εκδόσεις υπογράφονται με **το ίδιο κλειδί** (`signing/flare.jks`) ώστε οι ενημερώσεις να εγκαθίστανται από
πάνω. Το κλειδί είναι δημόσιο στο αποθετήριο: εγκατάστησε το Flare μόνο από εδώ. Για ιδιωτικό κλειδί, πρόσθεσε στο
*Settings › Secrets › Actions* τα secrets `FLARE_KEYSTORE_B64` (το αρχείο .jks σε base64), `FLARE_KEYSTORE_PASSWORD`,
`FLARE_KEY_ALIAS` και `FLARE_KEY_PASSWORD`.

## Καλό να ξέρεις

- Αυτοματισμοί, ιστορικό και ρυθμίσεις μένουν **στο τηλέφωνο**. Το Flare δεν έχει πρόσβαση στο Internet.
- Οι εντολές shell τρέχουν με τα δικαιώματα ADB του Shizuku: επικόλλησε μόνο εντολές που καταλαβαίνεις.
- Το όνομα του δικτύου Wi-Fi διαβάζεται μόνο με την άδεια τοποθεσίας (κανόνας του Android).

## Δομή του αποθετηρίου

| Φάκελος | Περιεχόμενο |
|---|---|
| `android/` | Η εφαρμογή (Kotlin, Jetpack Compose): μηχανή στο `core/`, υπηρεσίες στο `service/`, οθόνες στο `ui/` |
| `i18n/` | Τα κείμενα του περιβάλλοντος στις 23 γλώσσες |
| `scripts/` | Δημιουργία κειμένων, δοκιμή σε εξομοιωτή, βοήθεια για το χτίσιμο |
| `docs/` | Στιγμιότυπα και μεταφρασμένα README |
| `signing/` | Κλειδί υπογραφής του APK |
